# Growth Agent Skills

Open, vendor-neutral skills that help AI agents perform evidence-led growth marketing work.

## The operating loop

**Research → Plan → Create → Discover → Measure → Learn**

| Skill | Purpose |
|---|---|
| [`research-market-opportunity`](skills/research-market-opportunity/) | Find and validate market opportunities without overstating evidence |
| [`create-growth-marketing-plan`](skills/create-growth-marketing-plan/) | Convert evidence and business goals into priorities, initiatives, and measurement |
| [`build-content-growth-engine`](skills/build-content-growth-engine/) | Build a repeatable content, copywriting, distribution, and learning system |
| [`optimize-search-visibility`](skills/optimize-search-visibility/) | Improve discoverability across traditional and AI-assisted search |
| [`analyze-growth-performance`](skills/analyze-growth-performance/) | Turn growth data into decisions and executive-ready reporting |

## Design principles

- Evidence before confidence
- Explicit assumptions and limitations
- Actionable outputs with owners and decision rules
- Measurement built into every workflow
- No dependency on private company context

## Install

Copy an individual folder from `skills/` into the skills directory supported by your agent environment, or reference its `SKILL.md` directly. Each skill is self-contained and can be used independently.

## Status

This is an early public foundation. Real-world testing and contributions are welcome.
