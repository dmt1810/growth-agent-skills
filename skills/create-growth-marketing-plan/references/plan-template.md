# Growth Plan Template

## Initiative register

| Initiative | Audience | Journey stage | Hypothesis | KPI | Target | Owner | Effort | Timing | Decision rule |
|---|---|---|---|---|---|---|---|---|---|

## Experiment definition

For each experiment define the observation, hypothesis, intervention, audience, primary metric, guardrails, minimum runtime or sample rationale, success threshold, stop rule, owner, and follow-up decision.

## Resource scenarios

When exact budgets are unavailable, provide lean, base, and accelerated scenarios. State assumptions and what each scenario gains or sacrifices.

## Operating cadence

Define weekly execution review, monthly performance review, and quarterly strategy review only when appropriate. For each cadence specify inputs, decisions, and accountable owner.
